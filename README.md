ДЗ 1. Базовый Python

Файл: `homework_1.ipynb`. Данные — список `orders` в первой ячейке.

 Что должно получиться

1. Заказов — 8.  
   Ключи заказа: `order_id`, `customer`, `city`, `amount`, `status`, `email`.

2. После очистки первый заказ:  
   `customer: 'Анна Смирнова'`, `city: 'москва'`, `amount: 1250.5`.  
   Некорректные суммы: заказы 103 (`"нет данных"`) и 108 (`""`) → `amount: None`.

3. `paid` / `cancelled` — 6 / 2.  
   Сумма оплаченных — 9201.25.  
   Средний оплаченный заказ — 1840.25.  
   По городам: москва 4, казань 2, санкт-петербург 2.  
   Москва, `paid`, сумма > 1000: Анна Смирнова, Мария Орлова.

4. Все проверки — `OK` в каждой строке.

 Ручной пересчёт

- `paid`: заказы 101, 102, 104, 105, 107, 108 → 6.
- Сумма: 1250.5 + 700 + 2300 + 3100.75 + 1850 = 9201.25.  
  Заказ 108 без суммы не учитываем.
- Среднее: 9201.25 / 5 = 1840.25.

 Мутационный тест

- Заказ 102: `"amount": "700"` → `"abc"` — сумма оплаченных уменьшится на 700, заказов с суммой станет 4.
- Заказ 102: `"city": "Казань"` → `"  МОСКВА"` — москва 5, казань 1.
- Заказ 101: `"amount"` → `"900"` — Анна Смирнова пропадёт из списка задания 3.7.

 Ограничения
